HARDLE — DAILY MODE STATES

This file defines WHEN UI elements appear or disappear.
It does not redefine layout.

ACTIVE STATE
- Grid is editable
- Keyboard is visible
- Session timer is running
- Decryption State is visible

END STATE (WIN or FAILURE)
- Grid is locked
- Keyboard is hidden
- Session Summary is hidden
- Only final outcome content is visible
- No further interaction is possible

TIME EXPIRY
- Treated as FAILURE
- Uses the same END STATE rules
