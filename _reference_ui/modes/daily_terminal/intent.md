HARDLE — DAILY MODE (TERMINAL UI)

This file defines INTENT only.
Layout and visuals come exclusively from the Figma UI files.

SCOPE
- This intent applies ONLY to Daily mode.
- All other modes (Hard, Extreme, etc.) remain unchanged.
- The legacy Daily mode is fully replaced by this one.

CORE IDENTITY
- Daily mode is a terminal-style system interface.
- The player is an operator inside a system, not a casual player.
- The UI represents a decryption / breach process.

LANGUAGE RULES
- Do NOT use Wordle-style terminology.
- Do NOT use "greens", "yellows", "attempts", or playful copy.
- Use system language only (decryption, breach, session, signals).

STATE BEHAVIOR (HIGH LEVEL)
- The game has a clear ACTIVE state and a clear END state.
- When the game ends (win or failure):
  - Input is disabled.
  - Keyboard is hidden.
  - Diagnostic-only UI is removed or frozen.
  - The interface must feel final.

TIME
- Daily mode is time-bound.
- Session time is meaningful and authoritative.
- Time expiry results in a failure state.

RESULTS
- Success is communicated as a system breach.
- Failure is communicated as decryption failure.
- Outcomes are informational, not celebratory.

CONSTRAINTS
- Do not redesign the UI.
- Do not reinterpret the Figma layout.
- Do not merge this UI with other modes.
- Do not invent new screens or panels.

SOURCE OF TRUTH
- Figma UI files define layout, spacing, and visuals.
- This document defines intent and meaning only.
